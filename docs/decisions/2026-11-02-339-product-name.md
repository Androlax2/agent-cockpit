# Name the product Torlek

Issue #339. Decided by Theo on 2026-11-02, from the research in
[the naming report](../research/2026-11-02-339-product-naming.md) and
[the Torlek appendix](../research/339/torlek.md).

- **The product name is Torlek; the base command and identifier is `torlek`.** It is 6 ASCII
  letters, sounds the same in English ("TOR-lek") and French ("tor-lek"), is spelled the way it
  sounds, and has no known meaning in either language. It fits `torlek`, `torlek daemon`,
  `torlek-next`/`torlek-dev` profiles, `~/.config/torlek/`, `torlek-*` crates and `TORLEK_*`
  environment variables. It ends the collision with Red Hat Cockpit.
- **Why it survived:** no package in the checked registries, no marks in USPTO, TMview or WIPO,
  and no software business with the name (2026-11-02). The
  [appendix](../research/339/torlek.md) holds the checked table, its sources and its limits.
- **No product domain will be bought** (Theo, 2026-11-02). `torlek.dev` returned no registration
  but is not owned; `torlek.com` serves an unrelated HVAC company's page. Documentation, installers
  and update URLs use the GitHub repository rather than a product domain.
- **Not established:** legal clearance, a similar-mark or phonetic analysis, a native-speaker slang
  check, the official Nix index, `.sh`, and the GitHub name `torlek`, which is a personal account.
  Theo decides whether a clearance precedes the public-facing rename steps.
- **This record does not rename anything.** The rename is
  [#560](https://github.com/Androlax2/agent-cockpit/issues/560) in the Alpha 1 milestone, done in
  the order of the report's rename plan. The logo is #99.
- **Rejected:**
  - **Crewkiln and Runlark** (the provisional finalists): Crewkiln sounds manufactured and is hard
    to pronounce in French, and Runlark's "lark" sets a frivolous tone.
  - **The other six original proposals:** existing software collisions.
  - **Real words that fit, and vowel-dropped names in the style of herdr:** already used by
    AI-agent tools, and the second style reads as a herdr add-on.
  - **Torvel, Torvan and Sarvel:**
    - Torvel: a placeholder product site and a GitHub organization from August 2026.
    - Torvan: Torvan Medical, which sells medical devices with software.
    - Sarvel: a pending French trademark in classes 9, 35, 37, 38, 42 and 45, and a Japanese
      registration in class 9.
  - **Dorlek** is the backup if a later clearance blocks Torlek.
